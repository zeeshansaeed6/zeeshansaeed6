# Fonts

Subsets of two typefaces, embedded into the SVGs by `scripts/theme.mjs`.

- `anybody-display.woff2`: [Anybody](https://github.com/Etcetera-Type-Co/Anybody) by Etcetera Type Co, instanced at width 135 and weight 800. SIL Open Font License 1.1.
- `plex-sans-400.woff2`, `plex-sans-600.woff2`: [IBM Plex Sans](https://github.com/IBM/plex) by IBM. SIL Open Font License 1.1.

`metrics.json` holds each glyph's advance width so the build scripts can wrap text without a font library.
